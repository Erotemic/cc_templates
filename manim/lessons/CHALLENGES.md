# Independent mathematical animation challenges

These are deliberately **not** guided lessons. You decide how to represent
the mathematics in a Manim animation and where to put the code. A complete
solution should be something you can explain to another person.

| Challenge | Goal | Concepts to think about |
| --- | --- | --- |
| Newton's method | Watch an initial guess move toward a root. | tangent, iteration, error |
| Monte Carlo pi | Estimate pi by throwing random points at a square. | area ratios, randomness, convergence |
| Random walks | Animate a walker who makes random steps; compare many runs. | probability, position, reproducibility |
| Rotation vs. reflection | Show how two matrix transformations differ. | determinant, orientation, linearity |
| Fractal staircase | Build a self-similar image in successive stages. | recursion, scale, termination |
| Sorting algorithms | Make a sorting method visible without writing the numbers. | state, comparisons, invariants |
| A graph algorithm | Show a route-finding algorithm discover a path. | nodes, edges, frontier, shortest path |
| Fourier sketch | Approximate a periodic curve using several rotating circles. | sums of sinusoids, frequency, phase |

Also try a code-reading challenge: take a scene you haven't written,
find every `ValueTracker`, and explain which displayed objects depend on it.
