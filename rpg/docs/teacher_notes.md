# Teacher Notes

## Project shape
This is a battle-only vertical slice. It is intentionally scoped so students can see real game structure without being buried by an overworld, save files, or asset pipelines.

## Beginner-safe files
- `content/colors.py`
- `content/sprites.py`
- `content/characters.py`
- `content/teams.py`

## Intermediate files
- `content/moves.py`
- `content/audio.py`
- `render/effect_factory.py`

## Advanced files
- `core/rules.py`
- `core/ai.py`
- `battle/battle_scene.py`

## Suggested lesson order
1. Recolor and reshape characters.
2. Swap moves and rebalance stats.
3. Create a new move and a new battler.
4. Modify the math spell visuals.
5. Add a new status effect.


## Audio extension ideas
- Compare the two built-in generated tracks in `content/audio.py`, then have students swap or remix them.
- Let students create a sound family for one character class.
- Pair visual math-wave spell edits with matching audio-wave edits.
