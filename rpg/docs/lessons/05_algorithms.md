# Lesson 5 — Design a Decision-Making Algorithm

**Prerequisites:** functions, conditionals, lists, `min` or a simple loop.

Open `practice_enemy_strategy`.

## Predict

The target-selection scenario starts with:

- Workshop Hero: 20 / 52 HP;
- Storm Ranger: 19 / 46 HP.

Which has lower raw HP? Which has lower HP ratio? Predict which one the strategy
will target.

## Investigate

```bash
python lab.py scenario target_selection
```

## Modify

Change the strategy to choose lowest raw HP instead. Rerun the same scenario.

## Independent task

Design a boss strategy with at least two recognizable phases. Write the rules
in plain language before writing Python.

## Explain / transfer

Compare two correct target-selection algorithms. What objective is each one
optimizing?
