# Common Programming Sequence

These lessons form the common path before students choose a larger project.
They are organized around what students should be able to **predict, explain,
debug, and create**, not around a grade number.

1. [Read, predict, investigate, modify](01_predict_investigate_modify.md)
2. [Write a conditional from a specification](02_conditionals.md)
3. [Trace a loop and build a result list](03_loops.md)
4. [Find and repair bugs](04_debugging.md)
5. [Design a decision-making algorithm](05_algorithms.md)
6. [Create something original and explain it](06_make.md)

Each lesson contains:

- prerequisites;
- a prediction before execution;
- a supported investigation;
- a modification;
- an independent task;
- an explanation or transfer question.
