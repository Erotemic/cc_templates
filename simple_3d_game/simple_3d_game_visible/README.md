# Shadow Coin Hunt

A small first-person Ursina game with high-contrast colors, simple geometry, and a readable code layout.

## Install

```bash
pip install .
```

## Run

```bash
shadow-coin-hunt
```

or

```bash
python -m shadow_coin_hunt
```

## Controls

- WASD: move
- Mouse: look around
- Space: jump
- Left Shift: sprint
- R: restart after game over
- Q or Escape: quit
